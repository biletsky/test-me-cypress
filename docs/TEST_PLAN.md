# Test Plan — Test Me (Cypress)

## 1. Мета й підхід

Перевірити магазин https://test-me.vzl.one/ і його API.

- **API** для розрахунків, валідації, ізоляції та статусів: швидко і в цілих копійках.
- **UI** для того, що бачить покупець: checkout, суми в гривнях, кошик і порівняння, подвійний клік, XSS, мобільний режим.
- **Дані для UI** створюються API-запитом у середовищі відкритого браузера. Сценарій не проходить зайві екрани перед перевіркою.
- **Розрахунок сум** живе в `cypress/support/money.js`. Тести порівнюють відповідь із цим розрахунком.

## 3. Ризики та як їх знято

| Ризик | Захід |
|-------|-------|
| Rate limit (30 workspace/хв, 180 записів/хв) | токен на файл там, де тести не конфліктують (`quote.cy.js`); `createWorkspace()` чекає `Retry-After` при 429 |
| Спільний стан між тестами | `testIsolation` очищує `localStorage` → магазин створює нове середовище на кожен UI-тест; API — власний токен у `beforeEach` |
| Flaky async UI (quote, каталог) | асерти з ретраєм на фінальний стан (`expectTotals`, `expectTotalFound`), без `cy.wait(ms)` |
| Локаль / форматування грошей (`2 400,00 ₴` / `грн`, NBSP) | парсинг у копійки `parseUah`, а не пошук рядка |
| Публічне середовище може змінити дані (seed) | ціни й stock винесені в `fixtures/products.json`; `GET /api/health` повертає `seed` |
| Витік токенів | токени не логуються (`log: false`), не потрапляють у `Cypress.env`, у `.gitignore` є правило для `*token*` |

## 4. Поза покриттям (свідомо)

- Повний аудит доступності, контраст, екранні читачі, темна і світла тема.
- Клавіатурна навігація по діалогах (потрібен `cypress-real-events`).
- Закінчення строку токена через 24 години. Відповідь 429 перевірена через stub.
- Знижка з округленням вниз до копійки: поточні ціни кратні 100 копійкам, тож 10% завжди ціле.
- Другий браузер із тим самим token після «Почати заново».
- Навантаження і повна комбінаторика фільтрів.

## 5. Ізоляція й паралельність

- **API:** кожен тест (або файл, якщо стан не змінюється) створює свій `POST /api/workspaces`.
- **UI:** токен створює сам магазин. Кнопка «Почати заново» перевіряється окремо (TM-CHECKOUT-001, TM-FAV-002, TM-REV-002).
- **Набори:** `cypress/smoke` — короткий прогін, `cypress/e2e` — регресія. Запускаються окремими скриптами.
- **CI:** `.github/workflows/cypress.yml` ділить регресію і smoke на незалежні jobs. Кожен job створює власні середовища.
