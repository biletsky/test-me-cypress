## TM-CHECKOUT-001 — Оформлення замовлення з WELCOME10 і стандартною доставкою

| Поле | Значення |
|------|----------|
| Пріоритет / тип | P0 · позитивний, наскрізний UI |
| Передумови | «Почати заново» з підтвердженням; кошик, обране, замовлення порожні |
| Дані | p01 × 1; WELCOME10; standard; контакти за замовчуванням; «Успішна оплата» |
| Автотест | `cypress/smoke/checkout.promo.cy.js` |

| Крок | Дія | Очікуваний результат |
|------|-----|----------------------|
| 1 | «Орбіта» → «До кошика» | Повідомлення про додавання; лічильник кошика = 1 |
| 2 | Відкрити кошик | 1 позиція, кількість 1, ціна 2 400 грн |
| 3 | WELCOME10 → «Застосувати»; стандартна доставка | Товари 2 400; знижка 240; доставка 0; разом 2 160 грн |
| 4 | Заповнити контакти, «Успішна оплата» | Немає помилок валідації, кнопка доступна |
| 5 | Один раз «Оформити замовлення» | Успіх; «Мої замовлення»; рівно 1 POST і 1 замовлення «Підтверджено» на 2 160 грн; кошик 0 |
| 6 | «Деталі замовлення» | «Орбіта» × 1; 2 400 / 240 / 0; повний номер = id з відповіді API |
| 7 | Reload «Мої замовлення», відкрити кошик | Той самий номер, статус, сума; дубліката немає; кошик порожній |

Післяумова: у власному середовищі одне замовлення.
